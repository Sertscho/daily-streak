# Daily Streak 🔥

Tägliche Erfolgs-App nach dem „3 Gains pro Tag“-Prinzip aus *The Gap and the Gain* (Dan Sullivan & Benjamin Hardy):

- **Abends:** 3 Erfolge (Gains) von heute aufschreiben
- **Für morgen:** die 3 wichtigsten Ziele festlegen
- **Streak:** jeden Tag, an dem du es machst, wächst dein Feuer
